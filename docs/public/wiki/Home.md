# ag-mcp-gateway Wiki

[Русский](Home-ru.md)

The gateway runs on a workstation and gives several agent clients one local route to approved MCP tools. It separates profiles and environments, tracks tool health and latency, and exposes logs for troubleshooting. Use it when agents would otherwise maintain separate MCP connections and settings.

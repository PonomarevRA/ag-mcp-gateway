## Подключение и секреты

Выберите профиль и проверьте точный loopback-адрес. В обзоре смотрите состояние подключения и время последнего фактического вызова. **Переподключить** открывает и проверяет замену. Шлюз публикует её каталог после проверки и позволяет завершиться уже отправленным вызовам. Для включённого Basic на macOS используйте **Учётные данные MCP**. Перед сохранением в Связке ключей шлюз проверяет соединение.

Для локального токена шлюза используйте `token-set <имя-ключа>` и `access_token_keychain`. Резервный источник из окружения задаётся явно. Настройки и токены тестовой и production-сред хранятся раздельно.

## Журналы и метрики

```sh
ag-mcp-gateway --profile NAME status
ag-mcp-gateway --profile NAME logs --backend SERVER --limit 20
ag-mcp-gateway --profile NAME logs --trace-id TRACE_ID
```

Локальный сборщик использует токен профиля Bearer для `GET /api/diagnostics/v1/metrics`, `GET /api/technical-logs/v1/status` и `GET /api/technical-logs/v1/events`. Для опроса вперёд передавайте `journalEpoch` и `afterSequence` последнего принятого курсора. Для загрузки старых страниц используйте `beforeSequence`. Просроченный курсор получает HTTP 409 с `resetCursor`. Сначала зафиксируйте разрыв, затем продолжите сбор.

Квота каждого журнала по умолчанию 50 МБ, срок хранения семь дней. Каждый постоянный файл журнала ограничен 50 МБ. Очистка по возрасту выполняется при запуске и каждую минуту. SQLite может создать кратковременный файл отката. Счётчики сбрасываются при перезапуске. Токены оцениваются по размеру JSON. Сборщик должен учитывать отсутствующие измерения и счётчики потерь.

## Диагностика

| Симптом | Что проверить |
| --- | --- |
| Обзор не открывается | Запуск выбранного профиля и loopback-порт. |
| Браузер повторно запрашивает вход | Пользователь `gateway` и токен этого профиля. |
| Upstream 401 или 403 | Связка ключей или настроенный источник токена и права на MCP. |
| Инструмент отсутствует | Готовность MCP, профиль, запрет и обновление каталога. |
| Сборщик получил 409 | Зафиксировать разрыв и загрузить сохранившиеся страницы либо продолжить с новой отметки. |

Для штатной регистрации в Ag Observer его сборщик должен поддержать тип приложения шлюза, токен источника и выбор потоков technical/diagnostics. Другой локальный сборщик может использовать общий HTTP-контракт напрямую.
